# v0.5.0 follow-up: weather and airspace widget tests

Apply on top of `FPVManager_v0.5.0_flutter_test_hotfix_patch.zip`.
This follow-up changes **tests only** and does not alter production behavior.

1. The concurrent-request cache test now verifies the returned Futures share
   identity immediately, then yields one event-loop turn before asserting
   how many times `MockClient` was called. `MockClient` dispatch is asynchronous.
2. The airspace inspector tap now scrolls until the button is actually
   hit-testable within the current test viewport. Merely finding the widget
   or calling `ensureVisible` was insufficient in the 800x600 test case.
3. The route test now scrolls back to the top to reach the close button after
   inspecting lower content. Its list children are lazily built.

Run from the project root:

```powershell
flutter test test/features/weather/weather_models_test.dart --reporter expanded
flutter test test/features/airspace/airspace_check_sheet_test.dart --reporter expanded
flutter test test/features/weather/ test/features/airspace/ test/features/drones/drone_navigation_test.dart
flutter analyze --no-pub
```

No Dart/Flutter SDK is available in the authoring environment; the Dart test
changes are not marked as passed until executed on a Flutter installation.
Other previously reported full-suite timeouts (SQLite and map layers) are
unrelated and not addressed by this patch.
