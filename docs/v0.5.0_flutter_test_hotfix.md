# v0.5.0 Flutter analyzer / test hotfix

This patch is based on the supplied `FPVManager_v0.5.0_weather_source.zip`, not on any
uncommitted changes in a local checkout. Apply it on top of that version of FPVManager.

## Corrections

- **Compilation**: The MeteoSwiss CSV fixture uses `Map<String,String>` and `map['time']`
  has type `String?`; the test explicitly asserts a present timestamp using `!`.
- **Source attribution / airspace**: The shared fixture correctly contains
  `REQ_AUTHORISATION.MTOM_ALL` instead of legacy `REQ_AUTHORISATION`. Update the outdated
  test expectations without modifying the official-source classification in production.
- **Airspace widgets**: Scroll the `ListView` before looking for restriction code and
  route segment details so the tests work with the additional safety/attribution rows.
- **Drone navigation**: The map menu now has five items. Only Weather intelligence is
  accessible before globe readiness; the four globe-dependent options stay disabled.
- **Analyzer**: Remove a redundant provider cast and unused weather import; add ordinary
  `if` statement blocks (collection-if statements are deliberately unchanged), use
  `initialValue` for four `DropdownButtonFormField` widgets.

file locks, concurrent test load, or uncompleted asynchronous work if a suite
continues to time out in isolation. Especially examine `MapLayersSheet`'s
periodic age timer, terrain/source refreshes, and outstanding renderer requests.
