# Archived implementation notes

This directory holds **historical development notes** rather than the current
user or developer documentation. They describe intermediate implementations
from November 2026, including now-superseded LoS limits, draft RF and GPS Rescue
behavior and earlier battery model phases.

Use the maintained references instead:

- [User guide](../user_guide.md)
- [Flight simulation and radio](../user/flight_simulation.md)
- [Battery profile guide](../user/battery_and_power.md)
- [Developer guide](../developer_guide.md)
- [Radio and GPS Rescue architecture](../developer/radio_and_rescue.md)
- [Battery/energy architecture](../developer/battery_model.md)
- [Simulator and collision architecture](../developer/simulation_and_collision.md)

Archived notes are deliberately not edited to erase their historical context.
They must **not** be used to determine current defaults, limits or legal
requirements. New feature documentation belongs in the maintained guides,
not as a new date-stamped document at the `docs/` root.
